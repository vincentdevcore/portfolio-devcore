# Dev'coRe Portfolio

Portfolio personnel de **Dev'coRe**, développeur web & web designer.

Ce projet a été conçu afin de présenter mes compétences en :

- Développement Web
- Web Design
- UI / UX
- Création d'identité visuelle
- Branding & design graphique

## Aperçu

Ce portfolio met en avant plusieurs projets réalisés dans différents contextes :

### Projets présentés

- **Hell Coming**  
  Projet réalisé lors de mon stage chez EPI Studio pour une cliente spécialisée dans la sublimation textile.

- **Armor Argoat**  
  Création d'une identité visuelle et d'un logo pour une entreprise de marbrerie.

- **Kwerel SF6**  
  Site événementiel conçu pour des tournois Street Fighter 6 avec interface dédiée et panel administrateur.
